How to annotate (read once)

For each item you see a source text and a repaired label (positive / negative / neutral). Answer one question:

Is the repaired label consistent with the polarity expressed by the source text?

  • YES (consistent) — the label fairly reflects the text's sentiment polarity.
  • NO (distorted) — the label contradicts or misrepresents the text's polarity.
  • Judge polarity only (pos / neg / neutral), not fine-grained emotion, intensity, or aspect.
  • neutral is consistent when the text is genuinely mixed/factual; mark NO if the text is clearly pos/neg but labelled neutral.
  • Sarcasm / negation: judge the writer's intended polarity, not the surface words.
  • Shortcuts: Y = consistent, N = distorted, ←/→ to move.

When all items are answered, click Download my annotations and send the CSV back to the study coordinator.
